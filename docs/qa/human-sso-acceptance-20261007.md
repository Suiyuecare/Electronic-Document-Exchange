# 本人 SSO 與人員異動驗收紀錄

狀態：**待本人驗收，不能據此宣告正式上線通過**。
本表只記角色，不保存姓名、email、token、MFA、瀏覽器 profile 或真實公文。
驗收人已由使用者指定；五位均須本人操作，測試帳號／signed handoff 不替代。

## 每位共同檢查

1. 同一瀏覽器先由本人登入 Finance/APM；新開 EDOC，確認有權限可直接進入。
2. EDOC 直達網址、新分頁、重新整理各一次，不應重複要求 Google 登入。
3. 使用去識別化測試案件走自己的角色工作，不寄送真實公文。
4. 登出／換另一位後，不顯示前一位草稿、列表、檔案或遲到回應。
5. 網路失敗可重試；session 到期可本人重新登入，不假裝已儲存／已簽核。

## 停權／離職驗收

停權情境先以隔離環境及去識別化帳號執行；不為測試任意停用在職正式員工。
只有已核准的真實離職異動才在正式環境觀察，且只讀檢查未結與 session 拒絕。

- Finance 停用資訊到達後，舊 session 的敏感動作必須拒絕。
- 待交接在確認前不改簽核人或授權；總務與確認主任不得同人。
- 接任人須有效、同公司／租戶且適格；確認當下重新查驗資格。
- 新關卡須重看文件，不沿用前人勾選；已完成實際簽核證據不改寫。
- 原申請人離職且退回補正，由接任人建立關聯新案完整重跑；原案不改姓名／字號。
- 已用印／寄送只交接追蹤，不再次用印、寄送或改寫歷史。

## 執行限制

`tools/live_five_account_sso_acceptance.py` 是 privileged signed-identity probe，
不是此表的本人驗收工具。本次不得使用它隨機代入真實員工。其預設執行
會在讀取 secret／帳號及發送 handoff 前拒絕，避免誤記為人類 OAuth 驗收。

目前隔離交易測試的成功與本表 PENDING 分開記錄。前台、Supabase 完整
流程、本人驗收和發布檢查都完成前，不發布本次高風險交接功能。
