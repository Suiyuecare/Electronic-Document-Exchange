# 抽單、退回與不通過驗收

規則與十項驗收門檻見 [簽核操作規劃](../plans/20261006-approval-actions.md)。只涵蓋核准的內部公文與一般文件簽核；不啟用政府正式交換。

## 問題與改善

| 問題 | 改善 | 驗收 |
| --- | --- | --- |
| 退回補正與終止案件容易混淆 | 保留可重送的「退回補正」，新增終止性的「不通過（終止案件）」 | 不通過保留原檔、歷程、原因與實際決定人；後續修改／取消／重送／用印皆拒絕 |
| 抽單時機不明確 | 仍待簽核且未取得用印工作才能抽單；再送從第一關開始 | 非申請人、用印 claim、已核准／用印／寄發／結案及不通過拒絕；已簽歷程不刪除 |
| 下一關退回後檢閱版本可能被混用 | 退回上一關產生新關卡識別碼；沿用鎖定內容、不開放申請人修改 | 過期步驟與舊證據拒絕；第一關不提供退回上一關 |
| 真實介面下載後確認勾選仍鎖住；補正畫面藏住確認欄 | 完成對應檢閱才開放手動勾選，移至所有決定共用區 | 通過／補正／上一關／不通過皆實際瀏覽器送出；抽單不用假裝檢閱 |
| 重複點擊／同時決定可能造成部分寫入 | 操作 ID、請求 hash、版本 CAS、資料庫鎖與單一交易 | 同 ID 重試一次效果；變更內容重用 ID／過期／併發互斥操作拒絕；通知失敗整筆回滾 |
| 行政派發失敗或缺少有效承辦不清楚 | 前一批改善併同發布：有效名冊、交接提示、期限檢核、批次 scoped 查詢、無假成功 | 收文→派發→回文→主管追蹤隔離旅程，見五角色報告 |
