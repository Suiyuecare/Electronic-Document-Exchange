# 電子用印編輯：簡化與驗收紀錄

範圍僅限「電子用印」的 PDF 編輯區；保留桌機左側申請資料、右側約 65% 編輯區。這是已實作的本機驗收版本，**尚未部署正式前台**。

## 改善順序與結果

| 優先 | 原本的問題 | 簡化後 |
| --- | --- | --- |
| P1 | 一般／進階與十種工具同時競爭注意力 | 常用的選取、加文字、印章、騎縫章直接操作；其餘放「更多工具」 |
| P1 | 換頁、頁碼、縮圖及頁面整理重複 | 保留一組頁碼選擇；點「頁面」才展開縮圖、排序、旋轉、刪頁及合併 |
| P1 | 騎縫章設定長期占版面 | 點騎縫章才出現設定，選章在前，頁面範圍在後；關閉就回到選取 |
| P1 | 手機橫式 PDF 畫布被最小高度拉伸 | 顯示尺寸依 PDF viewport，畫布、SVG 與編輯座標一致 |
| P1 | 文字／細線難直接點選拖曳 | 增加透明操作區，最小 44 × 44 CSS px，不改輸出尺寸或印章尺寸 |
| P2 | A4 成功資訊、檔案資訊及 revision 重複占行 | 合併成檔名、頁數、原稿保留及「已保存」；離線、衝突、錯誤仍明確顯示 |
| P2 | 每次保存重新建立所有縮圖 | 重用已完成縮圖，只在頁面變更或渲染失敗時更新／重試 |
| P2 | 手機輸入與收合面板不易操作 | 44px 操作目標、16px 輸入字體、Escape 焦點返回、可用鍵盤展開複製頁面 |

## 使用方式

上傳 PDF → 加文字／選印章 → 直接點選或拖曳物件 → 預覽送簽確認版。

「更多工具」保留文字取代、圖片、形狀、勾選、螢光、安全遮蔽。「檢視」保留原稿、編輯版、送簽確認版、變更清單與精準縮放。安全遮蔽仍明確提示永久移除編輯版區域內容。

## 前後比較

使用相同的兩頁橫式 A4 合成 PDF、相同輸入文字、相同一般員工角色；沒有使用使用者合約或正式資料。Before 是原有進階介面，After 是相同能力改為按需展開。

| 比較項目 | Before | After |
| --- | --- | --- |
| 桌機預設可見控制項 | 35 | 19 |
| 手機預設可見控制項 | 34 | 19 |
| 桌機編輯區高度（1440 × 1000） | 約 1458px | 約 853px |
| 手機編輯區高度（390 × 844） | 約 1645px | 約 784px |

這些是指定合成文件與操作狀態的量測，不是所有文件的固定高度或效能保證。前後對照圖與原始報告位於 `tests/.artifacts/editor-simplified/`。

## 驗收要求與證據

- 員工、執行長兩個合成角色；桌機、手機分別檢查，另驗證無可用印章狀態。
- 實際瀏覽器經本機 HTTP API 上傳、加字、保存、復原／重做、選擇工具、換頁、開關面板及原稿唯讀檢視。
- 編輯幾何檢查：canvas、stage、SVG 尺寸差不超過 1 CSS px；文字直接點選與拖曳另行驗證。
- 檢查無整頁水平溢出、可見表單與按鈕操作區至少 44px、手機輸入字級 16px、可見鍵盤焦點與焦點返回。
- UI 切換不改 manifest、已保存內容或 dirty generation。相同初始上傳／加字流程的 HTTP 寫入次數前後一致。
- 跨公司讀取仍回 403，過期 revision 保存仍回 409；錯誤與衝突未被折疊藏起。
- 額外桌機／手機 correctness 流程包含圖片上傳、確認刪頁、重開草稿、文字複製及產生 prepared PDF；輸出保持正確頁面與中文內容。

驗收腳本：`tools/verify_editor_simplified_browser.py`、`tools/verify_editor_correctness_browser.py`。新增回歸：`tests/test_editor_simplified_controls.py`。

最終驗證結果：

- 完整自動測試執行 991 項，零失敗；其中 81 項因未啟用指定資料庫／外部驗收環境而跳過，不計為已驗證。
- 簡化介面最新瀏覽器驗收：員工／執行長 × 桌機／手機，共 4 條流程、123 項檢查全部通過；包含實際滑鼠點選、拖曳、後端保存與復原座標。
- 簡化與既有介面重點回歸 68 項全部通過；correctness 瀏覽器桌機／手機各 13 項通過。
- 未使用實機 iPhone／Android，也沒有執行 Firefox／WebKit；手機結果是 Chromium 響應式模擬，不宣稱實機 Safari 已驗收。

對照圖：`tests/.artifacts/editor-simplified/comparison-desktop.png`、`comparison-mobile.png`；合併檢視：`comparison.html`。

## 沒有變更的項目與發布邊界

沒有修改 API、資料庫、Storage 上傳、掃毒、簽核關係、權限、公司／部門選擇、印章原圖存取、鎖定規則或正式交換 provider。騎縫章仍依各組定位，印章尺寸不可任意拉伸。

本機瀏覽器驗收使用隔離 SQLite／Storage、合成 Finance 名冊與合成登入，不代表正式 SSO 或 Supabase 的新一輪驗收。沒有建立正式申請、簽核、用印或寄送，也沒有呼叫正式電子公文交換。

發布順序：本機回歸與對照確認 → 使用者同意部署 → CI／預備環境檢查 → 正式前台部署與版本、互動驗證。尚未進行部署步驟。
