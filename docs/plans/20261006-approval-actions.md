# 簽核操作與驗收規則

## 規劃

| 操作 | 可執行者與時機 | 結果 |
| --- | --- | --- |
| 抽單 | 申請人；仍有目前待簽核關卡，且尚未開始用印 | 停止本輪、回到草稿；再送出必須重跑全部簽核 |
| 退回上一關 | 目前簽核人或有效代理人；已有上一關通過 | 前一關與後續關卡重新檢閱；不開放申請人修改送簽文件 |
| 退回補正 | 目前簽核人或有效代理人 | 申請人修改後重新送簽，不代表終止案件 |
| 不通過 | 目前簽核人或有效代理人 | 終止案件；不得補正、再送簽、抽單、用印或寄發 |
| 通過／通過並加簽 | 目前簽核人或有效代理人 | 前進至下一關或指定加簽人員 |

全數簽核完成、用印工作已被取得、已用印、寄發中／已寄發、結案或不通過後，禁止抽單。第一關沒有上一關時，使用「退回補正」，不顯示「退回上一關」。所有撤回／退回／不通過必須填寫原因；所有簽核決定都須檢閱目前鎖定版本及附件。

## 驗收指標（全部使用去識別化資料）

1. 申請人可在第一關及部分核准後抽單；原始版本、已通過者及歷程不消失，重新送簽從第一關開始。
2. 非申請人不可抽單；非目前簽核人、失效代理人、停用帳號及跨公司無權限者不可決定。
3. 第二關退回上一關後，產生新關卡識別碼，舊檢閱證據不能重用；第一關沒有此操作。
4. 退回補正仍可修改與重送；不通過則保留原因、實際簽核人與時間，後續關卡停止，申請人收到通知。
5. 不通過後，所有修改、抽單、取消、重新送簽與簽核 API 都拒絕；不產生用印檔或發送工作。
6. 用印已取得工作／已用印／發送／結案階段，不顯示抽單，直接呼叫 API 也拒絕。
7. 同 operation id 重試只有一次效果；改動內容重用識別碼、過期關卡及併發互斥操作回報衝突，無部分寫入。
8. 桌機、平板、手機操作名稱一致；不通過以警示樣式呈現，確認視窗有原因及終止結果，預設焦點在取消；失敗保留輸入與行內錯誤。
9. PostgreSQL 公用／共享 EDOC namespace 皆通過交易、權限及併發測試；瀏覽器角色不可直接執行變更 RPC。
10. 僅發布 CI 通過的 main；先預覽驗收，再核對正式健康檢查與版本。正式政府交換不啟用。

## 介面所有權

沿用 Finance 配色、現有 native 控制項與 shared modal 的焦點／遮罩／關閉機制。不新增另一套 Dialog；API 回傳可操作動作為權限來源。失敗不得假裝成功或自動重送；409 更新最新資料並重新檢閱。
