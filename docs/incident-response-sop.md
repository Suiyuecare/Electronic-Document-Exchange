# 資安事件通報與應變 SOP

版本：2026-05-23  
責任人：行政部主任  
協作角色：總務、主任、執行長

## 1. 事件分級

| 等級 | 條件 | 初始處置時間 |
|---|---|---|
| P1 | 憑證外洩、未授權交換、密件外洩、資料庫遭破壞 | 15 分鐘內 |
| P2 | Token 異常、交換中心大量失敗、可疑登入、附件病毒警示 | 30 分鐘內 |
| P3 | 單一帳號鎖定、單一附件掃描失敗、排程延遲 | 4 小時內 |

## 2. 初始應變

1. 保存現場：匯出 audit log、API log、登入紀錄、交換事件、通知派送紀錄。
2. 隔離風險：停用可疑帳號、撤銷 Token、暫停排程或限制 IP。
3. 通知窗口：行政部主任通知總務、主任與執行長。
4. 維持證據完整性：不得刪除原始紀錄；所有處置需新增 audit log。

## 3. jAgent / 電子交換事件

若事件涉及電子公文交換：

- 暫停送交 jAgent 的高風險任務。
- 保留封包、交換事件、回覆碼、附件雜湊。
- 確認是否涉及誤送、漏送、重送或退回補正。
- 依主管機關、交換中心或內部資安程序進行通報。

## 4. 個資與密件事件

若事件涉及個資或密件：

- 立即確認資料範圍、下載者、時間、IP、裝置。
- 啟用密件隔離與下載凍結。
- 保留浮水印下載紀錄。
- 主任抽核是否有越權存取。

## 5. 復原作業

1. 修復帳號、Token、憑證、設定或資料問題。
2. 使用備份或版本紀錄進行復原。
3. 驗證公文主檔、附件、PDF 版本、交換事件與 hash manifest。
4. 復原後重新執行 production readiness。
5. 補發必要通知並更新事件單。

## 6. 事後檢討

事件結束後 5 個工作日內完成：

- 根因分析
- 影響範圍與時間線
- 已採取處置
- 未來改善措施
- 權限、流程、排程或通知規則調整
- 主任簽核
