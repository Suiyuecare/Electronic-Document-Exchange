# 保存年限與稽核證據政策

版本：2026-05-23  
責任人：行政部主任、主任

## 1. 保存範圍

本系統應保存下列資料：

- 公文主檔
- 收文與發文附件
- PDF 押章前後版本
- 用印申請單與用印紀錄
- 交換任務與交換事件
- 通知派送紀錄
- 登入紀錄、裝置紀錄、IP 限制紀錄
- 操作 audit log
- 檔案雜湊與 hash manifest

## 2. 保存年限原則

| 資料類型 | 建議保存 | 說明 |
|---|---:|---|
| 一般收發文 | 10 年 | 依公司文書保存政策與往來機關要求調整 |
| 涉及長照服務品質、稽核、補助或主管機關裁處 | 15 年 | 建議提高保存年限 |
| 密件、重大爭議、訴訟或調查案件 | 永久或凍結至解除 | 解凍前不得刪除 |
| audit log、登入紀錄、交換事件 | 至少 7 年 | 需支援不可否認性與事後追查 |
| 備份檔 | 依備份輪替政策 | 正式環境另受 Supabase / Storage 備份策略約束 |

## 3. 刪除與凍結

- 尚在簽核、稽催、補正、交換異常或調查中的案件不得刪除。
- 密件與重大事件需由行政部主任與主任共同解除凍結。
- 刪除前需產生待刪清冊、核准紀錄與最後 hash manifest。

## 4. 稽核抽樣

每季至少抽核：

- 收文 5 件
- 發文 5 件
- 交換失敗 3 件
- 押章 PDF 3 件
- 密件或個資附件 3 件
- 備份復原 1 次

抽核應確認：

- 文號、文別、速別、密等、主旨、附件清冊完整。
- 交換事件有 accepted、failed、completed 或補正紀錄。
- PDF 押章前後版本與 SHA-256 可驗證。
- 操作紀錄可追溯到使用者、角色、IP、裝置與時間。

## 5. 稽核輸出

- 季檢報告
- 抽樣清單
- 缺失與補正追蹤
- 主管簽核紀錄
- 版本化保存於 `docs/` 或正式文件管理系統
