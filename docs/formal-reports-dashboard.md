# 正式報表與主管儀表板

## 主管儀表板

主管、主任、執行長與行政部主任登入後，首頁會顯示主管營運儀表板。儀表板只整理主管需要決策的資訊，不顯示總務或系統管理細節。

- 今日決策重點：依 SLA、交換成功率、異常件與逾期件自動判斷。
- 風險排序：逾期、交換失敗、退回補正、待用印與待簽核依風險排序。
- 部門負載：依部門待辦件數與可作業帳號估算負載，提示是否需改派或加簽。
- 快捷作業：看簽核、處理逾期、正式報表、通知中心。

## 正式報表

正式報表產製後會建立報表編號、產製時間、產製角色、統計期間、資料口徑、主管結論與報表雜湊。

目前納入的資料口徑：

- 收文主檔：待登錄、待分派、已收文、異常待處理。
- 發文主檔：草稿、待清稿、已封裝、等待確認、交換完成、交換失敗、退回補正。
- 流程控管：待處理、待審核、待查核、退回補正。
- 稽催追蹤：翌日查核、逾期提醒、未收確認、退回補正。
- 歸檔保存：雜湊通過、需複核、已封存。
- 操作紀錄：報表產製、篩選、匯出與稽催建立。

## 匯出格式

- JSON：完整正式報表資料，供系統保存或內控簽核。
- CSV：主管月報或例會摘要。
- 稽核 JSON：正式報表加上報表操作紀錄，供法遵或內控抽核。

## 主管結論判定

- 通過：SLA 大於等於 90%、交換成功率大於等於 95%、且無逾期件。
- 觀察追蹤：少量異常或 SLA 未完全達標，但未超過改善門檻。
- 需主管改善：異常件或逾期件過多，需要主管建立稽催、改派、加簽或要求補正。
