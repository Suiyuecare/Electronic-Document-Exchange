# 一般文件電子用印：選章與列印位置

## 範圍

本次只調整電子用印頁的選章體驗，讓上傳的一般文件／合約 PDF 可以清楚選擇款式、大章、小章及騎縫章。用印公司沿用申請資訊的單一公司選擇器與 Finance 授權清單，預設自己的單位；不新增第二組可互相矛盾的公司值。

「紙本用印位置」指 PDF 輸出、列印的實際章位，不代表新增免簽核、離線紙本核准或不同的正式電子交換流程。

## 畫面與操作

| 項目 | 調整前 | 調整後 |
| --- | --- | --- |
| 用印公司 | 左側公司欄位，右側選章時不易確認 | 左側為用印公司；選章區顯示同一公司的名稱並可返回公司欄位 |
| 印章款式 | 款式、大小混在單一印章清單 | 選款式，再選大章／小章；有同款同尺寸多枚章時才選具體章名 |
| 缺少章檔 | 泛稱沒有 current 版本 | 保留選定款式／尺寸並說明尚無可用印章，不自動換用其他款式 |
| 紙本位置 | 需自行理解編輯器座標 | 以 PDF 頁面設定列印位置，支援拖曳與既有精準位置調整 |
| 騎縫章 | 與一般選章的關係不清楚 | 共用款式／尺寸，針對相鄰頁成組加入，各組位置獨立調整 |
| 手機 | 同一長清單 | 款式／大小並排，套用頁面與加入章位往下排列，保留完整操作與 44px 觸控區 |

## 安全與相容性

- 不新增資料表、API、角色權限或正式交換 provider。
- 不變更印章尺寸政策；一般申請人不能改變校準寬高、比例或已鎖定檔案。
- 款式與尺寸只是篩選條件，實際加入章位仍綁定印章 ID、檔案 ID、雜湊及尺寸。
- 選擇款式、大小或公司不會偷偷替換已放置的印章。
- 切換公司沿用保存原草稿、確認後新建另一公司草稿的流程；不移轉原檔或章位。
- 已送簽、原稿／確認版唯讀、上傳中及公司切換中不得新增或變更章位。
- 新章位維持最上層；歷史鎖定版本的 renderer 與雜湊不變。
- 不匯入或啟用尚未完成去背、尺寸與品質確認的實際印章。

## 驗收標準

1. 同一份三頁 A4 可加入不同款式的大章、小章，以及逐組不同位置的騎縫章。
2. 目前頁／全部頁、拖曳／精準調整、保存／重開的章位與檔案綁定相同。
3. 選定款式沒有小章時，不能自動加入另一款小章或大章。
4. 不可加入其他公司的印章、停用印章、未驗證版本或未校準尺寸。
5. 簽核前鎖定每枚章的版本；最後 PDF 使用各章位的獨立版本，保留原始 PDF。
6. 以本機合成帳號／印章測試桌機及手機，保留相同資料的 Before／After 截圖，不操作正式資料。

實作、測試與正式部署是不同階段；本文件本身不表示已推送或部署。
