# Finance 頁首一致性修正

## 範圍與優先序

僅調整 eDoc 六個主要頁面共用的 Header（P1 視覺一致性）；保留頁面名稱、權限、通知與待辦資料、登入、重新整理、回模組頁、登出及手機選單行為。沒有修改 Finance、APM、表單、簽核流程、資料庫或公文輸出。

參照來源為 Finance 正式版 `assets/styles/finance-core.css?v=14fe6b2b38a8ac2e` 與使用者提供的截圖，不採用尚未更新的本機 Finance CSS。

## 驗收

- 60 項頁面框架、重新整理、登入及公文字型回歸測試全部通過。
- 去識別化本機帳號，375、390、430、760、820、900、1180、1440、1920px 共九種寬度。
- 一般與超長標題／姓名均無頁面水平溢出、控制項遮擋或 JavaScript 錯誤。
- 通知入口、重新整理的實際 API 讀取與忙碌狀態、手機開關選單、Escape 與導覽正常。
- BEFORE 資產雜湊符合前版 HEAD；AFTER 符合修正後 HTML／CSS／JS。
- 未變更 JavaScript、後端及資料；正式交換環境未呼叫。

可重跑：`python tools/verify_finance_header_browser.py --phase before`（修改前）、`--phase after`（修改後）。對照畫面與測量結果位於本機 `tests/.artifacts/finance-header-20260925/{before,after}/`，不納入版本庫。
