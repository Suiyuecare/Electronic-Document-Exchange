# 操作細節防呆控管

本系統將操作分為日常作業、流程異動與高風險作業三個層級。日常查詢維持快速；會對外送出、改變權限、產生正式紀錄或影響營運設定的動作，必須通過額外檢核。

## 收文

- 登錄前檢查單位、保存年限與重複登錄。
- 分派前檢查承辦人、期限不可早於今天、狀態必須為待分派或異常待處理。
- 批次分派或密件分派需二次確認。
- 誤送、漏送必須填寫可追蹤的異常說明。

## 發文與交換

- 送交 jAgent 前檢查清稿、封裝、憑證與附件資安狀態。
- 已送出或已交換完成的公文不可重複送出。
- 重送僅限交換失敗或退回補正。
- 送交與重送需輸入指定確認字樣。

## 簽核與用印

- 退回、抽回、改派必須填寫簽核意見。
- 加簽、會辦、改派必須指定目標角色。
- 已完成節點不可再異動。
- 送簽用印前需完成清稿，且印鑑必須啟用、已上傳圖檔、登錄實體長寬。

## 通知與背景任務

- 真實通知測試需檢查 Email 格式與內容，並輸入指定確認字樣。
- 交換失敗即時警示、通知重送、背景任務立即執行都需二次確認。
- 未啟用的背景任務不可立即執行。

## 維運、備份與法遵

- 正式系統設定需 HTTPS，且需輸入指定確認字樣後才能儲存。
- 備份還原演練不可指定正式環境，RTO/RPO 目標需大於 0。
- 法遵驗收簽核會寫入不可否認紀錄，需輸入指定確認字樣。
